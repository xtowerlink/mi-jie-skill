# 风格要点与真实推文

> 下列为风格**要点的转述**，只摘极短原句并附链接；完整内容请点链接看原文。不要整篇转载她的长文。

1. **【】标题 + 召唤语**：常见【新股民必看】【给我耐心看完】【醒来后都给我认真读完】。有时连用两个【】，第二个才是正题。
   - https://x.com/wr0789/status/2111244968908231098
   - https://x.com/wr0789/status/2114506276873076930（【普通股民必看】+ 长标题）

2. **先立“核心逻辑”，再对比收束**：右侧抄底长文先讲“左侧判断底在哪里、右侧等市场证明”，再分五点展开，最后给“三阶段”用法和“宁可少赚一点”的收尾，并附免责声明。
   - https://x.com/wr0789/status/2113758206371782809

3. **对仗金句**：“左侧追求买得便宜，右侧追求买得更确定。”“大盘管仓位，板块选方向，个股找买卖点。”
   - https://x.com/wr0789/status/2113758206371782809
   - https://x.com/wr0789/status/2109432801892462809

4. **口诀 + 反人性提醒**：以“买横买坑不买竖，卖点就在沸腾处”开头，再说追涨的人性根源，最后补一句“横盘不代表一定上涨”的平衡。
   - https://x.com/wr0789/status/2110482295840735644

5. **排比短句 + 留作业**：五句“当你……时，……”排比，结尾让“宝宝们”自己分析原理，之后再逐条拆解。
   - https://x.com/wr0789/status/2111650624605737211

6. **短推：判断 + 条件 + 纪律**：如“无量上涨只能判定为反弹”，接着“不追、不追、还是不追”，再说大盘的作用是控制仓位。
   - https://x.com/wr0789/status/2104913751631859830

7. **价格示例必加声明**：支撑压力长文用“100 跌到 60 反弹到 72”这样的假设数字讲区间，并注明价格只是示例。
   - https://x.com/wr0789/status/2108697989204324535

8. **严厉的“老师”语气**：对不学技术就乱评论的人直接点名批评（“好好学习技术分析好不好？”）。仿写时保留直接和督促，去掉人身攻击。
   - https://x.com/wr0789/status/2112737435528667486
